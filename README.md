### Leo Wallet Integration Guide

Welcome to the **Leo Wallet** integration guide! This **README** will walk you through the steps to quickly integrate
Leo Wallet into your **React** application.

## Features

- **Easy Wallet Connection**: Effortlessly connect Leo Wallets without the need for pre-built buttons.
- **Transaction Requests**: Seamlessly request transactions for your smart-contract.

## Getting Started

To start using the Leo Wallet follow the next steps.

1. Clone this repository to your local machine:

```
git clone https://github.com/Kelp1e/leo-wallet-transaction.git
```

2. Install the following libraries using npm or yarn:

```
npm install --save \
    @demox-labs/aleo-wallet-adapter-base \
    @demox-labs/aleo-wallet-adapter-react \
    @demox-labs/aleo-wallet-adapter-reactui \
    @demox-labs/aleo-wallet-adapter-leo
```

3. Start your **React** application.

### Running on Your Machine

1. Clone this repository to your local machine `git clone https://github.com/Kelp1e/telegram-mirror.git`
2. Create an `.env` file based on the `.env.example` file and configure it.
3. Create and activate a virtual environment `python -m venv venv ; venv/Scripts/activate`
